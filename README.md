## 📌 About This Project

A fully responsive personal portfolio website built with pure **HTML, CSS, and JavaScript** — no frameworks, no dependencies. Showcases my skills, projects, education, and contact info in a clean, modern design deployed on Vercel.

---

## ✨ Features

- 🎨 **Clean, modern UI** with smooth animations and hover effects
- 📱 **Fully responsive** — works on mobile, tablet, and desktop
- 🚀 **Fast loading** — pure HTML/CSS/JS, zero dependencies
- 📥 **Resume download** — direct PDF download button
- 🔗 **Project showcase** — links to all GitHub projects with tech stack tags
- 📬 **Contact section** — email, GitHub, LinkedIn links
- ☁️ **Deployed on Vercel** with global CDN
